RÉGLAGES DE GÉNÉRATION
- Mode : Text to Sprite.
- Modèle : Epic. Une variante. Coût affiché : 1 crédit.
- Direction : 3/4.
- Détail : Moderate.
- Height : préréglage 128 px pour la génération.
- Advanced Cleanup : désactivé.
- Isometric, Rotation et Sprite pack : désactivés.

Copie la description du personnage dans Describe your sprite. Colle ces mêmes notes dans Style notes :

Bold, continuous silhouette. Large blocks of mid-tone color. Solid, clearly filled shapes. Simple two-tone shading and clean pixel edges. Single character, no scenery, no lettering.

AVANT D’EXPORTER
1. Sur le damier ou avec BG, vérifie que le corps, les vêtements et l’équipement sont pleins. Les ouvertures naturelles, comme entre les jambes, peuvent rester transparentes.
2. Dans Crisp Sizes, choisis la première taille nette indiquée par SpriteLab. Pour Ronce, c’est 94 px. Cette valeur varie selon le sprite. Le 128 px sert de réglage de départ.
3. Exporte un PNG transparent. Laisse la tête, les pieds et les accessoires dans le cadre. On ajustera la taille à l’écran dans le jeu.
